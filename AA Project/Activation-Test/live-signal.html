Presence controls the LED

VL53L1X → A4/A5 → front-zone decision → D8 → jumper → D7 + A0.

PRESENT means a valid object is in the configured front zone. A still target can remain present. Distance is used internally; it is not the main signal.

Entry: any valid target within 1.5 m. Hold: within 1.6 m. No software minimum distance. Entry dwell: 150 ms. Exit dwell: 200 ms. Invalid readings close the output. Standalone LED firmware starts on power-up and has no timed ON cutoff.

PIR is disconnected. ToF detects objects; it does not identify a person. D7/A0 measure the command wire.
